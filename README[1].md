# EduMind AI Website Demo

## Run
1. Extract `edumind-ai-website.zip`.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or install VS Code's **Live Server** extension and right-click `index.html` → **Open with Live Server**.

## Demo login
Email: `demo@edumind.ai`
Password: `demo123`

You can also use Create Account to create a browser-local demo account.

## Features in this frontend prototype
- Landing page matching the EduMind AI mockup
- Login and signup UI
- Profile setup/edit
- Academic journey and subject CRUD
- Skill assessment quiz with scoring
- Daily planner, task completion, priorities and Rescue Mode
- Skill passport and career goal
- Progress dashboard
- Responsive desktop and mobile layout
- Data saved in browser localStorage

## Limitations
This is a frontend prototype. Google/Apple/GitHub buttons are illustrative only, email/password accounts are stored locally and are not secure production authentication. AI insights are demo/rule-based, not a live AI model. For production use, connect a backend, secure auth, database and server-side AI API.
